# GMR-111: connected notebook terrain

Owner direction: terrain attached to walls, floors, neighbours or level bounds must read as a connected mass. Fold the GMR-107 pool seams and fading ledge-end side contours into this renderer change. The requested review order was GMR-106, GMR-111, GMR-110, GMR-109. On resumption, Opus had already merged the earlier queue including polish into main; this branch integrates main `3ef1167` and adds the remaining terrain work. No Codex PR merge is performed.

Locked constraints: collision is authoritative; render only; no simulation, input, level geometry, replay hashes or hero changes. Reuse approved 0015/0016 black thin ink and paper-negative texture; red remains confined to hazards. No copied reference art or layouts. No delay between death and retry. Bundle thresholds unchanged.

Bounded choices: split edge contacts at their actual geometry intersections, omit shared/boundary contours, use world-anchored crosshatching for connected mass, retain the calibrated kit foliage only on exposed walkable tops, and reserve feathered skirts for unattached platforms. Exposed ceiling undersides get thin doubled contours and drips. Corners join both contour strokes across convex and concave turns, with shared intervals omitted, so T-junctions do not acquire rectangle seams. Borders continue the same hatch field.

Outside terrain uses one shared 256 px hatch texture and disjoint screen-sized pattern surfaces projected from the current camera. Lower/side mass fills the visible area; only authored top-bound columns continue upward. Output storage is bounded by viewport area plus rounding, rather than overview world dimensions. Camera changes update world phase; stationary frames reuse the existing surfaces. Hidden Canvas surfaces shrink to 1×1 and scene shutdown removes each private TileSprite texture. The debug tile/pixel counts include this storage.

Acceptance: all Section 1 play/overview screenshots show connected terrain; floating platforms still float; tests exercise bounds, neighbours, hazards, partial contacts and slopes; renderer/HMR resources remain bounded; fingerprints unchanged; repository checks and budgets pass. Before/after screenshots, pixel checks and replay evidence will accompany the PR.

Isolated full solids have a thin bottom contour and fading interior; they are not open-bottom one-way decks. No new backgrounds, parallax, motifs or 42-piece asset deliverable is introduced by this focused topology fix.
