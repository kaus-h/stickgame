# Art prompt library

Versioned prompts for ChatGPT image generation (doc 32, GMR-40). One file per prompt, named `<id>-<short-name>.md`, containing the exact prompt text, the date, the result's verdict and any follow-up edits.

Rules (doc 07A): describe qualities in plain language; never name deadanddetached or any other living artist; never upload the artist's images as references; only our own approved sheets may be used as reference images.
